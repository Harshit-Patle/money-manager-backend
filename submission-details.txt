Money Manager Web Application – Submission Details

Project Description:
A modern web application for managing personal and business finances with real-time analytics, transaction tracking, and comprehensive filtering capabilities. Built with React and Node.js, it features interactive dashboards, category-wise spending summaries, account transfers, and time-based transaction editing rules.
